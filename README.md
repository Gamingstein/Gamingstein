<img src="assets/hd-projects.svg" alt="03 — Projects" />

<br /><br />

Five systems worth opening the hood for. Each one starts with a different problem; the interesting part is the shape the solution takes.

<br />

<details>
  <summary><strong>PROJECT AETHER</strong> · event-driven AI as an organism</summary>

  <br />

  [Open Project Aether →](https://github.com/Gamingstein/Project-Aether)

  <br /><br />

  An AI ecosystem for Discord, modelled as a biological organism. Microservices communicate through a Redis Streams nervous system; a compiled LangGraph `StateGraph` acts as the Brain; MCP handles tool discovery; sentiment gives the system a mood layer; ChromaDB supplies asynchronous memory.

  <br />

  `Python` `LangGraph` `Redis` `ChromaDB` `MCP` `Prometheus` `Grafana`
</details>

<br />

<details>
  <summary><strong>AEGIS</strong> · a messenger built for the future threat model</summary>

  <br />

  [Open Aegis →](https://github.com/Gamingstein/Aegis)

  <br /><br />

  A post-quantum secure peer-to-peer messenger with a zero-trust architecture. ML-KEM-768 and ML-DSA-65 establish the cryptographic foundation; Double Ratchet provides forward secrecy; encrypted storage, memory zeroization, and an emergency wipe keep the terminal interface backed by serious failure handling.

  <br />

  `Rust` `ML-KEM-768` `ML-DSA-65` `Double Ratchet` `TUI`
</details>

<br />

<details>
  <summary><strong>VITALLINK</strong> · keeping the clinical signal alive</summary>

  <br />

  [API](https://github.com/Gamingstein/Vitallink-graphql) · [Dashboard](https://github.com/Gamingstein/Vitallink-frontend) · [Mobile app](https://github.com/Gamingstein/Vitallink-Mobile)

  <br /><br />

  A real-time patient monitoring platform in three connected parts: a GraphQL API, a Next.js dashboard for clinicians, and an Expo/React Native app that brings IoT vitals and AI-driven insights to the point of care.

  <br />

  `TypeScript` `Prisma` `GraphQL` `Next.js` `Expo` `React Native`
</details>
