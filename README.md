<br/><br/>

**[Project Aether](https://github.com/Gamingstein/Project-Aether)** · `python` `langgraph` `redis` `chromadb` `prometheus`
Event-driven AI ecosystem for Discord, modelled as a biological organism — each microservice is an "organ" communicating over a Redis Streams nervous system. The Brain reasons through a compiled LangGraph `StateGraph`, auto-discovers tools via MCP, tracks mood through a sentiment engine, and pulls context from an async ChromaDB store — all observable through Prometheus + Grafana.

**[Aegis](https://github.com/Gamingstein/Aegis)** · `rust` `ml-kem-768` `ml-dsa-65` `tui`
Post-quantum secure P2P messenger with a zero-trust architecture. ML-KEM-768 / ML-DSA-65 (FIPS 203/204), Double Ratchet protocol, forward secrecy, memory zeroization, encrypted storage, and an emergency wipe — all behind a terminal UI.

**[VitalLink](https://github.com/Gamingstein/Vitallink-graphql)** · `typescript` `prisma` `nextjs` `expo` `react-native`
Real-time patient monitoring platform in three parts: a [GraphQL API](https://github.com/Gamingstein/Vitallink-graphql) (TypeScript/Prisma) powering both a [Next.js dashboard](https://github.com/Gamingstein/Vitallink-frontend) for clinicians and an [Expo/React Native app](https://github.com/Gamingstein/Vitallink-Mobile) that pulls IoT vitals and AI-driven insights straight to the point of care.

**[Nexus](https://github.com/Gamingstein/Nexus)** · `go` `cli`
Dynamic CLI devtool for scaffolding, managing, and stress-testing Go backend systems — professional-grade, built for speed.

**[Cacheflow](https://github.com/Gamingstein/Cacheflow)** · `python` `textual` `sqlite` `pydantic`
Production-grade terminal UI for personal finance tracking.
